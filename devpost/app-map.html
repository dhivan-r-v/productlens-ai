App Overview & Core Journey

ProductLens AI is a proof-of-concept e-commerce auditing tool that bridges structured sales data with computer vision. When a merchant uploads a product photo and sales CSV, it executes deterministic math locally in Pandas, invokes Google Gemini for multimodal qualitative analysis, and renders four structured cards.

The Core Code Route (Follow One Action)

Here is where each part of the workflow lives in the project codebase:

static/app.js (Lines 80–135)

Stop 1: Client Ingestion & Schema Inspection

When the user selects or drops a CSV, handleCsvFile reads the first line client-side using the HTML5 File API and verifies that required columns (date, product, price, units_sold, revenue) are present. If any column is missing, the Analyze button is disabled and an inline error is displayed before any network traffic is initiated.

app/analyzer.py (process_sales_csv)

Stop 2: Deterministic Data Processing (Pandas)

The uploaded CSV bytes are parsed into a Pandas DataFrame. Pandas calculates total revenue, unit volume, average selling price, and second-half trend trajectory. Math is kept 100% deterministic so numerical metrics never hallucinate.

app/analyzer.py (run_multimodal_analysis)

Stop 3: Multimodal AI & Pydantic Validation (Gemini)

The image bytes and the Pandas summary are sent to Google Gemini with strict prompt instructions: treat all connections as testable hypotheses or factors worth investigating and ground metrics directly in the provided CSV fields. Gemini's JSON output is validated against app/schemas.py before returning to the frontend.

To Change This, Start Here

  • Add/Change Required CSV Columns: Update REQUIRED_COLUMNS in app/analyzer.py and REQUIRED_CSV_HEADERS in static/app.js.
  • Refine AI Prompt Rules: Edit the system prompt in app/analyzer.py > run_multimodal_analysis.
  • Update Visual Theme or Colors: Modify CSS variables (--primary-900, --emerald-600) in static/styles.css.
  • Modify Results Cards Layout: Adjust the HTML structure in static/index.html (lines 100–180).

A Practice to Reuse: Deterministic Logic + AI Qualitative Synthesis

What we practiced: Rather than passing raw CSV data to an LLM and asking it to calculate sales totals and trends, we delegated arithmetic to Pandas and qualitative reasoning (aesthetic evaluation, cross-modal hypotheses) to Gemini.

Why this matters on future projects: Large language models are probabilistic text predictors, not calculation engines. Using Python for deterministic data transformations and reserving the model for visual synthesis, pattern interpretation, and hypothesis framing makes AI applications vastly more reliable, auditable, and cost-efficient.

How to Run This Project

To run the application locally at any time:

python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

Then open http://127.0.0.1:8000 in your browser.
